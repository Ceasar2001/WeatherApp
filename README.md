# 🌤️ Weather App

A lightweight and responsive weather app built with **HTML**, **CSS**, and **JavaScript**. It fetches and displays real-time weather data for any city using a weather API.

## 🚀 Features

- 🔍 Search weather by city name
- 📡 Real-time weather updates
- 🌡️ Displays temperature, condition, humidity, and wind speed
- 🎨 Simple and clean UI
- 📱 Fully responsive for mobile and desktop

## 🌐 Technologies Used

- HTML5
- CSS3 (with optional Flexbox or Grid)
- Vanilla JavaScript (ES6+)
- [OpenWeatherMap API](https://openweathermap.org/api) *(or any other weather API you're using)*
